# 《我如何用 IBKR 本地 CSV + Obsidian 估值死线锁，做了一个专治“被套后乱改信仰”的冷酷 AI 风控官》

> 零付费数据 API（$0/月）、纯本地 Python 确定性重算 SOTP/FCFE、外加一套不讲人话的 Caveman 极简电报体裁决。

---

## 一、为什么亏大钱的，往往不是不会算估值的人？

作为一个用 IBKR（盈透）或长桥做港美股、又习惯在 Obsidian 里认真写 SOTP / FCFE 估值模型的个人投资者，我踩过最深的一个坑，根本不是“找不到上涨 10 倍的标的”，而是下面这个极其真实的心理轨迹：

1. **建仓时无比冷静**：写了一整页逻辑——“这笔买美光（MU）是做 HBM3E 良率爬坡 + DRAM 涨价周期的基本面波段，如果 Q4 良率不到 75% 或者合约价环比转跌，SOTP 估值立刻下修，直接砍仓。”
2. **浮亏 -16% 时大脑开始自我欺骗（Thesis Creep）**：财报出来良率只有 62%，价格跌破成本线。这时候人类大脑本能地不想承认自己错了，于是复盘笔记里开始出现这样的句子：
   > *“虽然 Q4 HBM 良率不及预期，但 AI 存储超级周期才刚开始，把波段仓位转为长期价值投资死扛，忽略短期波动。”*
3. **更隐蔽的“容忍度松动（Tolerance Creep）”**：上季度写死线时要求云业务增速 `>= 10%`，这季度跌到 `4.2%`，你不声不响把笔记里的及格线改成了 `>= 4.0%`，然后心安理得地告诉自己“还在安全区间内”。

而如果你把这种持仓丢给通用大模型聊天？它多半会像个和稀泥的老好人安慰你：*“短期确实承压，但长期 AI 需求依然存在，建议结合自身风险偏好综合评估……”*——等于没说，甚至帮你一起合理化拖延止损。

券商自带的报表（IBKR PortfolioAnalyst）只会算冰冷的夏普比率和净值回撤，**它根本不知道你当初买入这只股票的 3 条核心假设到底破产了没有。**

## 二、我的解法：ThesisBreaker（零 API 成本的逻辑证伪纪律官）

结合最近 GitHub 上两个很有启发的项目思路——[`tradermonty/claude-trading-skills`](https://github.com/tradermonty/claude-trading-skills) 的 **“零付费数据 API + 本地 YAML 记忆库 + 仅输出风险敞口姿态（不自动下单）”**，以及 [`JuliusBrussee/caveman`](https://github.com/JuliusBrussee/caveman) 的 **“砍掉一切废话与套话的冷酷电报体”**，我开源了一个纯本地工具：**[ThesisBreaker](https://github.com/SnowyLumiere/thesis-breaker)**。

核心机制只有 4 条铁律：

1. **强制 3 条可证伪数字死线（Falsifiable Kill-Switches）**：每只建仓标的必须在 Obsidian YAML frontmatter 里写清楚 3 条可量化指标、方向（`>=` / `<=`）、死线阈值与估值折扣（`haircut_pct`）。没有卡或不足 3 条的仓位，一律判为 `UNTRACKED_NAKED_POSITION`（裸奔仓位）。
2. **SHA-256 死线锁（防事后改口）**：建仓时运行 `thesis-breaker lock`，把 `initial_strategy_type` 和 `locked_threshold` 锁死。哪怕你后来偷偷把阈值改松，审计脚本依然拿 `locked_threshold` 判你破产，并直接点名抓出 **容忍度松动**。
3. **Python 确定性 SOTP / FCFE 重算**：不让 LLM 瞎拍脑袋估值，直接由确定性代码重新计算分段 SOTP / 两阶段 FCFE 内在价值和安全边际（MOS）。
4. **Caveman 极简三行冷酷输出**：禁止写任何安慰话，每只持仓只输出 3 行。

## 四、控制每周维护摩擦 < 15 分钟

工具再硬核，如果每周还要手工抄几十行财报数字到 YAML 里，很快就会弃坑。因此我顺手内置了一个本地 **3 指标财报快报抽取器（`thesis-breaker extract`）**：只从你贴进 Obsidian 的财报表格或摘要里自动提取那 **3 个死线数字** 并回写 frontmatter，实测每周维护不超过 5 分钟。

项目全部开源、零第三方依赖（Python 3.9+ 直接跑）、零 API 费用：
- GitHub 仓库：`https://github.com/SnowyLumiere/thesis-breaker`
