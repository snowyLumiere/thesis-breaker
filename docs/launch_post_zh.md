## 二、为什么亏大钱的，往往不是不会算估值的人？

球友里不缺会搭 SOTP、会算 FCFE、天天盯财报的高手。但真实交易里最致命的，根本不是“不知道明天涨跌”，而是**亏钱后的大脑自我保护机制**：

- **逻辑漂移（Thesis Creep）**：波段买成股东，事件驱动买成长线价值。
- **容忍度松动（Tolerance Creep）**：把原本的“增速不能低于 10%”悄悄改成“只要还是正增长就行”。
- **问大模型没用**：你把持仓发给普通 AI 聊天，它十有八九像个和稀泥的老好人：“短期承压但长期仍有韧性，建议结合自身风险偏好……”——不仅没拦住你，还在帮你合理化拖延止损。
- **看券商报表也没用**：IBKR / 长桥 / 富途的账户分析只会告诉你夏普比率和最大回撤，**它根本不知道你当初买入这只票的 3 条核心前提是不是已经彻底证伪。**

## 三、我的解法：开源纯本地工具 ThesisBreaker（$0 API 费用）

我做了一个开源、纯本地、零第三方依赖的小工具 **[ThesisBreaker](https://github.com/SnowyLumiere/thesis-breaker)**，思路极度克制：

- **不预测明天涨跌、不接任何付费行情 API（$0/月）**：只读你本地导出的 IBKR / 长桥 / 富途持仓 CSV + Obsidian 估值卡，隐私数据 100% 留在你电脑里。
- **强制 3 条可证伪死线 + 建仓防篡改锁**：买入时锁死核心门槛，事后偷改门槛直接抓现行。
- **Python 确定性重算估值，不让 AI 瞎拍脑袋**：SOTP 分部估值、两阶段 FCFE 折现和安全边际全部由本地代码确定性重算。
- **每周维护不到 15 分钟**：最怕估值工具太重坚持不下去，内置了本地 **3 指标财报快报抽取器**——把财报表格粘贴到本地 Markdown/CSV，一键抽出你盯的那 3 个数字自动回写笔记并重算估值。
- **只输出风险敞口姿态，严禁自动下单**：只负责在你嘴硬时抽你一巴掌，最终买卖权 100% 归你自己。

仓库开源地址（MIT 协议，Python 3.9+ 开箱即用，自带上面 4 只标的的 Demo 可一键体验）：
- GitHub：`https://github.com/SnowyLumiere/thesis-breaker`
- 体验命令：克隆仓库后执行 `PYTHONPATH=src python3 -m thesis_breaker demo`
